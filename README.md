## 🚀 Cara Menjalankan Portofolio

Website ini dibuat dengan **Pure HTML5, Modern Tailwind CSS, dan Vanilla JavaScript**. Anda **tidak perlu menginstal Node.js atau paket dependensi tambahan apa pun**:

1. Buka folder ini di File Explorer Windows.
2. **Klik dua kali pada file `index.html`**, atau klik kanan lalu pilih **Open with Google Chrome / Microsoft Edge**.
3. Website portofolio interaktif Anda langsung berjalan responsif!

## 🌐 Cara Mengunggah (Deploy) ke Internet Secara Gratis

Agar portofolio ini memiliki tautan online aktif untuk dicantumkan pada resume atau profil LinkedIn:

### Opsi 1: GitHub Pages (Gratis & Direkomendasikan)
1. Buat repositori baru di [GitHub.com](https://github.com) dengan nama `portofolio` (pilih *Public*).
2. Unggah seluruh file folder ini (`index.html`, folder `assets/`, dan file terkait).
3. Buka tab **Settings** > **Pages** pada repositori GitHub.
4. Pada bagian **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
5. Website Anda aktif dalam hitungan menit di `https://username.github.io/portofolio/`.

### Opsi 2: Vercel / Netlify (Drag & Drop Langsung)
1. Kunjungi [app.netlify.com/drop](https://app.netlify.com/drop) atau [vercel.com](https://vercel.com).
2. Tarik (*drag & drop*) seluruh folder projek ini ke halaman web Netlify/Vercel.
3. Website langsung aktif dengan alamat URL instan berkecepatan tinggi.
